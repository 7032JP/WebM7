# 機種比較（対応機種の機能一覧）

WebM7 が対応する 7 機種の機能差の一覧です。画面上部の機種タブの右に並ぶ**能力バッジ**は、下表の **MMR/TWR** と **77AV機能** 以降の行を選択機種に合わせて点灯表示しています（広い画面の PC では、同じ場所に選択中の機種のメイン RAM・VRAM 容量も表示されます）。**スチール切替** と **第2水準漢字** の行はバッジに出ません（スチール切替は MMR/TWR と同じく FM-7 と FM-77 を分ける違いです）。

|------|:----:|:-----:|:------:|:--------:|:----------:|:--------:|:-------------:|
| **MMR/TWR** | — | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| **スチール切替** | — | ✅ | 常時解除 | 常時解除 | 常時解除 | 常時解除 | 常時解除 |

## 各バッジの内訳

- **MMR/TWR** — メモリ管理（MMR）とテキストウィンドウ（TWR）。FM-77 から搭載されました。有効な間はメイン CPU の動作がやや遅くなります。
- **スチール切替** — 画面表示のための「サイクルスチール」を、ソフトから解除できる機能。WebM7 では、FM-77 で解除を切り替えられ、FM77AV 系は常に解除された状態で動作します。
- **77AV機能** — 4,096 色表示（320×200）、キーボードのキースキャン読み込み、ALU（論理演算ユニット）とハードウェア直線描画。FM77AV 系すべてが持つ基本機能です。
- **2DD** — 2DD（640KB）ディスクへの対応。ソフトからのドライブモード切替（2D / 2DD）が働きます。
- **DMAC** — DMA コントローラによるディスク転送。対応ソフトでディスクの読み書きが CPU を介さず行われます。
- **高速MMR** — メモリ管理（MMR）を使っても遅くならない高速モードを持つ機種です。WebM7 では、MMR/TWR の使用中にソフトがこのモードを選ぶとステータスバーの MMR ランプが緑になりますが、メイン CPU の速さは変えていません（MMR/TWR の使用中はやや遅いままです）。FM77AV40 もこのモードの切り替えを受け付けるため、ランプは同じように緑になります。
- **AV40機能** — 640×400 ライン表示と 262,144 色表示（320×200）。
- **第2水準漢字** — 第 2 水準漢字 ROM（KANJI2.ROM）。FM77AV40・FM77AV40EX/SX は本体に搭載し、FM77AV20EX ではオプションです。WebM7 では、この 3 機種で使えます。
- **40EX機能** — 2 面 VRAM、拡張サブシステム ROM、辞書 ROM。ハードウェアウィンドウには、まだ対応していません（設定は受け付けますが、表示には効きません）。

## 機種の一言メモ

| 機種 | 発売 | ひとこと |
|------|------|---------|
| FM-7 | 1982 | ベースモデル。FM 音源・漢字 ROM・FDD はオプションで追加可能 |
| FM-77 | 1984 | 3.5 インチ 2D ドライブを内蔵。MMR/TWR とサイクルスチール切替を備える |
| FM77AV | 1985 | 4,096 色とキースキャンを備えた AV 系の初代 |
| FM77AV20 | 1986 | FM77AV に 2DD 対応を加えたモデル |
| FM77AV20EX | 1987 | AV20 に DMAC・高速MMR を追加（第 2 水準漢字 ROM はオプション） |
| FM77AV40 | 1986 | 400 ライン・26万色・DMAC・第 2 水準漢字 ROM を備えた上位機 |
| FM77AV40EX/SX | 1987/1988 | AV40 の完成形。高速MMR・2面VRAM・辞書 ROM 等を追加 |

※ EX 系のうち SX は 40 系（FM77AV40SX）のみ存在するため、本表では「FM77AV40EX/SX」とまとめて表記しています（WebM7 では同一機種として扱います）。
