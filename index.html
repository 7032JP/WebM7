WebM7 — FM-7 / FM77AV Web Simulator

        
WebM7 は、ブラウザで FM-7 系の動作を体験し、対応ソフトウェアの開発・検証に利用できるシミュレータです。

        既定では同梱の互換 ROM セット（独立実装。本体は MIT License、第三者素材由来の漢字字形は対象外。詳細は LICENSE-AltROMs.md）で動作するため、ROM ファイルの用意は不要です。お手持ちの ROM ファイルを使うこともできます。


        
ROMファイルの取り扱いについて

        ・本シミュレータが同梱・配信するのは、独立実装の互換 ROM セット（本体は MIT License。配布元は 7032 Alternative ROMs）のみです。純正 ROM は同梱も配信もしません。漢字系 ROM の字形の条件は LICENSE-Shinonome.md を参照してください。

        ・利用者がご用意されたROMファイルはユーザーのブラウザ内（ローカル環境）でのみ処理します。ROMデータがサーバーに送信・保存されることはありません。


        
選択した機種に合う ROM を指定してください。

使い方


        
1. ROM の供給元を選ぶ / ROMファイルを読み込む（ROM Files パネル）

        
本シミュレータは同梱の互換 ROM セットを常に土台として動作します。そのうえで、ROM 1 本ごとに供給元を選べます。各 ROM の行にある選択で「同梱互換」か「自分の ROM」を指定してください（例: FBASIC30.ROM だけ、あるいは KANJI.ROM だけをお手持ちのものにする、といった使い分けができます）。指定はブラウザに保存され、次回以降も維持されます。現在どの組み合わせで動作しているかは、同じパネル上部の ROM Set 表示で確認できます。

        
    
        
  • 同梱互換（既定） — 独立実装の互換 ROM セット（本体は MIT License）を使用します。ROM ファイルの用意は不要で、そのまま起動できます（行の横に「互換」と表示されます）。漢字 ROM（第1水準・全機種）も同梱されており、漢字表示に対応しています。ソフトウェアの動作条件は、下記の互換 ROM の互換性情報を参照してください（辞書 ROM を使うかな漢字変換には対応していません）。漢字系 ROM の字形の条件は LICENSE-Shinonome.md を参照してください。
    同梱互換 ROM の BASIC は、プログラムをアスキー形式（SAVE ,A と同じ形式）だけで読み書きします。中間コード（バイナリ）形式で保存されたファイルは読み込めません（COMPATIBILITY.md §3.2）。お手持ちのプログラムファイルをそのまま使う場合は、FBASIC30.ROM の行を「自分の ROM」に切り替えてください。機械語ファイル（SAVEM / LOADM）の形式は従来どおりです
    • 
        
  • 自分の ROM — お手持ちの ROM ファイルを読み込んで使用します。ROM ファイルを読み込むと、その行は自動的に「自分の ROM」に切り替わります（行の横に「OK」と表示されます）
    • 
        

        
「自分の ROM」に指定する行には以下の ROM ファイルが必要です（ご自身が適法に所有する実機から取得したものを用意してください）。


        
FM-7 / FM-77 共通ROM

        

        
ファイル名内容

        
FBASIC30.ROMF-BASIC V3.0 ROM（本体搭載 ROM。起動に常に必須）

        
BOOT_DOS.ROMDOS ブート ROM。FM-7 系を Boot Mode: DOS で起動する場合に必須

        
BOOT_BAS.ROMBASIC ブート ROM。FM-7 系を Boot Mode: BASIC で起動する場合に必須

        
SUBSYS_C.ROMサブシステム ROM（CGフォント内蔵）。起動に常に必須

        


        
FM77AV 追加ROM

        
FM77AVモードで起動する場合は、上記に加えて以下のROMも必要です。

        

        
ファイル名内容

KANJI.ROM漢字 ROM（JIS第一水準）。FM77AV以降は必須。FM-7 / FM-77 では任意（漢字ROMカード相当。指定すると漢字を使うソフトで漢字が表示されます）

        
SUBSYSCG.ROMキャラクタージェネレータ ROM（FM77AV 系で統合されたもの）

SUBSYS_B.ROMサブシステム Type-B ROM

        


        
FM77AV40EX / SX 追加ROM

        
FM77AV40EX / SX で起動する場合は、上記に加えて以下の ROM も必要です。

        

        
ファイル名内容

        
EXTSUB.ROM拡張サブシステム ROM

        
DICROM.ROM辞書 ROM

        
KANJI2.ROM漢字 ROM（JIS第二水準）

        

        
読み込み方法は2通りあります。

        
    
        
  • フォルダ指定 — 「Folder」で上記ファイルが入ったフォルダを選択
    • 
        
  • 個別指定 — 各 ROM を1つずつファイル選択
    • 
        

        
各行の右端のタグで、その ROM が今どこから来ているかが分かります。

        

        
表示意味

        
OK「自分の ROM」を指定していて、ファイルも読み込み済み

        
互換「同梱互換」を指定（同梱の互換 ROM で動作）

        
補完「自分の ROM」を指定しているがファイルが未登録で、同梱互換 ROM で補って動作

        

        
ROM 名の横の 必須 / 任意 バッジは、選択中の機種の ROM 構成を示します。

        
「自分の ROM」に指定した行のファイルがまだ読み込まれていない場合は、その行だけ同梱の互換 ROM で自動的に補って起動します（パネル上部の ROM Set に補完中の件数が出ます）。

        
Clear ROMs ボタンを押すと、ブラウザに保存した ROM だけを消去できます（ディスクや Library はそのまま残ります）。供給元の指定もすべて「同梱互換」に戻ります。


        
2. メディアイメージを管理する（Library パネル）

        
Library は、ディスク (D77) とテープ (T77) をブラウザ内で管理する仮想メディアの棚です。

        

        【PC のファイルへの影響について】

        Library への取り込み・挿入・論理FMT・複製・名前変更、ドライブへの抜き差し、
        さらに BASIC からのディスク書き込み (SAVE 等) は、すべてブラウザ内で完結します。

        お使いの PC 本体にある D77 ファイルは変更されません。
        PC 本体へ書き出されるのは、Disk Images パネルの「Save」ボタンか Library の「Exp」ボタン
        （.d77 書き出し）を押したときだけです。元の D77 ファイルを上書きしたくない場合は、別名で保存してください。

        
    
        
  • 取り込み (ファイル選択) — 物理ファイル (.d77 / .2d / .t77) を棚に追加
    • 
        
  • ＋2D / ＋2DD — 論理フォーマット済みの空ディスクを新規作成 (DISK BASIC からすぐ SAVE できます)
    • 
        
  • ▶0 / ▶1 / ▶T — 棚の項目を Drive 0 / Drive 1 / Tape へ挿入
    • 
        
  • ⬆Commit — 紐付け中のドライブに未反映の変更があるとき表示。押すと棚側へ反映
    • 
        
  • 論理FMT — ディスクを論理フォーマットし、DISK BASIC で SAVE 等の書き込みができる状態にします。内容を消去したいディスクや、物理フォーマットのみのディスクを書き込み可能にしたいときに実行してください
    • 
        
  • Exp / Ren / Dup / Del — 書き出し / 名前変更 / 複製 / 削除
    • 
        
  • 挿入中の項目には [Drive0] 等のタグが付きます。棚へ反映するときは Save より先に ⬆Commit を押してください
    • 
        
  • Eject 時に未反映があれば「反映する / 破棄する」確認ダイアログが出ます
    • 
        


        
3. ディスク（Disk Images パネル）

        
D77 形式 / 2D 形式のディスクイメージを「Drive 0」「Drive 1」に直接セットできます。Library 経由の方が
        複数イメージの管理に向いていますが、シンプルに 1 枚を試す場合はこのパネルで OK です。

        
    
        
  • ファイル選択で .d77 / .2d を読み込み、Eject で取り出し
    • 
        
  • 最近使ったファイル — 一度読み込んだファイルは履歴に残り、次に「ファイルを選択」を押すと先に一覧が開きます。行を押すだけで同じファイルを再度セットできます（Drive 0 / 1 で共通の一覧。Library から挿入したものも含まれます）。「Choose a new file…」でファイル選択ダイアログ、「✎」で表示名（メモ）、「×」で 1 件削除、「Clear history」で全消去。↑ / ↓ と Enter でも選べます
    • 
        
  • 履歴は PC のファイルへの参照と、開いた時点の中身の控えをブラウザ内に保存します（ディスク・テープそれぞれ 20 件まで）。参照を保持できるブラウザでは履歴から開くたびに PC の最新のファイルを読み直し（権限の確認が出ることがあります）、読み直せないときは開いた時点の控えが残っていればそこから復元します。履歴の中身は BASIC からの書き込みで更新されず、PC のファイルへ書き戻されることもありません
    • 
        
  • Clear Disk Cache ボタンは、ブラウザにキャッシュしたディスクイメージ・ファイル参照と、最近使ったファイルの履歴（ディスク・テープ）を消去します（ROM と Library は残ります）
    • 
        
  • SAVE "0:NAME" / SAVEM で書き込まれた内容はブラウザ内にのみ反映されます。PC へ書き出すのは Save ボタン（.d77。Library の項目は Exp）を押したときだけです。
    • 
        
  • セット中のディスク情報（2D / 2DD、シリンダ数 C・サイド数 H・トラック当たりセクタ数 R・セクタ当たりバイト数 N）をドライブごとに表示
    • 
        
  • 読み書き中のアクセス状況・動作状態（トラック / セクタ / 状態）は画面下のステータスバーに表示されます
    • 
        
  • 高速読み込みモード（既定 ON）: シーク（ヘッド移動）を加速して高速にロードします。OFF にすると実機相当のシーク速度・回転タイミングで動作します
    • 
        


        
4. テープ（Tape Image パネル）

        
T77 形式・WAV 形式のカセットテープイメージを「Tape Image」にセットできます。

        
    
        
  • T77 テープイメージ形式に対応
    • 
        
  • WAV 形式（PCM 8bit / 16bit、モノラル・多チャンネル）にも対応し、テープ信号として再生
    • 
        
  • REW ボタンでテープを巻き戻し、Eject ボタンで取り出し
    • 
        
  • 最近使ったファイル — ディスクと同じく、一度読み込んだテープは履歴に残り、「ファイルを選択」で先に一覧が開きます（WAV は中身を控えないため、参照を保持できないブラウザでは選び直しになります）
    • 
        
  • テープ読み込み中（モーター ON 時）はシミュレータが自動的に高速化されます
    • 
        
  • BASIC モードで起動後、RUN ""、LOAD、LOADM でテープから読込
    • 
        
  • BASIC SAVE / SAVEM で書き込んだ内容は自動的に録音され、録音→.t77（T77 形式）または 録音→.wav（PCM WAV 形式）ボタンでファイル保存できます（録音クリア で録音をクリア）
    • 
        
  • 詳しい SAVE / LOAD 手順、WAV の読み込み・保存と取り込み時の注意点は テープ操作マニュアル を参照
    • 
        


        
5. BASIC Paste

        
テキストを BASIC 画面へ自動入力できます。

        
    
        
  • BASIC 起動後（同梱互換 ROM では 7T-BASIC）、TXT/BAS ファイルを選ぶか Paste clipboard でクリップボードの内容を 1 文字ずつ自動入力
    • 
        
  • 英数字・記号とタブ・改行のほかの文字（日本語など）は読み飛ばされます
    • 
        
  • BASIC プログラムのリストを貼り付ければ、そのままプログラムとして入力されます（入力後 RUN で実行）
    • 
        
  • Stop で中断できます
    • 
        
  • BASIC キーワードは大文字推奨（小文字だとトークン化されない場合があります）
    • 
        


        
6. 起動（機種タブ・ハードウェアパネル・Options パネル）

        

        

        
    
        
  1. 画面上部の機種タブで機種を選択（FM-7 / FM-77 / FM77AV 〜 FM77AV40EX）
    2. 
        
  2. Boot Mode（BASIC / DOS）を機種別ハードウェアパネルで選択。FM-7（FM-7 / FM-NEW7 スキン）は画面下の背面パネル右端の DIP スイッチ（BOOT）、FM-77 は前面ボタン列の BASIC ボタン（押し込み = BASIC）、FM77AV 系は下部帯の BASIC / DOS ボタンです
    3. 
        
  3. ハードウェアパネルの電源スイッチで起動（もう一度押すと停止。画面下の Pause で一時停止・Resume で再開）
    4. 
        

        
画面（Screen）をクリックするとキーボード入力がシミュレータに渡ります。

  • Toolbar 1行目 — 画面下のバーに以下の機能があります。

      • 
            
    • 📷 — 現在の画面を PNG 画像として保存
      • 
            
    
        
    •

      • 
            
    • Memory — FM77AV 時のメモリ状態 (BASIC ROM/RAM / MMR / TWR / MMR Map / 物理メモリマップ)、State Dump ボタン
      • 
            
    • Keyboard — キー入力表示、FM-7 キーボードレイアウト、BREAK キー変更
      • 
            
    • Palette — 画面モードに応じたパレット表示 (Digital 8色 / 4,096色 / 262,144色)。320x200 / 262K モードではアナログパレットキャンバスも表示
      • 
            
    • Sound — PSG / SSG / FM 各チャンネルの音量メーターとレジスタを表示
      • 
            
    • Input — Input Monitor パネルの開閉 (後述)
      •

右側 — サイドパネル

        

        
セクション内容

        
OptionsFM Sound Card（FM-7 / FM-77 のみ）、Mouse、Joystick 1 / Joystick 2（接続したゲームパッドの割り当て）、Cursor → Ten Key（カーソルキーをテンキー代用）の選択。機種は画面上部の機種タブ、電源・リセット・Boot Mode は機種別ハードウェアパネル、Pause と 📷（PNG保存）は画面下のツールバーにあります

        
ROM FilesROM ファイルの読み込み（フォルダ一括 or 個別指定）。各 ROM の横のタグ（OK / 互換 / 補完）で供給元を確認できます。ROM Info で読み込み済みROMのサイズ・ハッシュを確認可能（Copy ボタンでクリップボードにコピー）

        
Libraryディスク (D77) / テープ (T77) をブラウザ内で管理する仮想メディアの棚。ファイル選択で取り込み、＋2D / ＋2DD で論理フォーマット済みの空ディスクを作成、▶0 / ▶1 / ▶T でドライブ・テープへ挿入、⬆Commit で棚へ反映。論理FMT / Exp / Ren / Dup / Del も可能

        
Disk ImagesD77 / 2D 形式のディスクイメージを Drive 0 / Drive 1 にセット。セット時にファイル名を表示。Save ボタンで書き込み後イメージを .d77 保存（書き込み後は * を表示。自動では保存しません。Library に反映するには ⬆Commit、PC へ保存するには Save）。Eject ボタンで取り出し。セット中ディスクの情報（2D / 2DD など）を表示。読み書き状況とドライブ動作状態は画面下のステータスバーに表示

        
Tape ImageT77 / WAV 形式のテープイメージをセット。REW（巻き戻し）、Eject ボタン。CMT LED 付き。録音→.t77 / 録音→.wav で書き込み内容を保存（録音クリアで消去）

        
BASIC PasteTXT / BAS ファイルの選択、または Paste clipboard でクリップボードの内容を BASIC 画面へ 1 文字ずつ自動入力。Stop で中断

        


        
Input Monitor

        
ツールバー 2 行目 (Debug Panels) の Input ボタンで開閉するフローティングパネルです。

        
    
        
  • Held Keys — 現在ブラウザ上で押下中のキー一覧
    • 
        
  • FM-7 Key — シミュレータに渡されたFM-7キーコード（16進数）とキーバッファ残数
    • 
        
  • Joystick — 最初に見つかった接続済みのゲームパッドの、スティックの方向とボタン 2 つの状態を表示
    • 
        


        
ジョイスティック

        
PCのゲームパッドを接続すると、FM-7/FM77AV のジョイスティックとして使用できます。

        
    
        
  • 自動認識 — ブラウザが対応するゲームパッドを接続すると、Options セクションの Joystick 1 / Joystick 2 のプルダウンに自動で一覧表示されます（一度割り当てたゲームパッドは、次に接続したときも同じポートへ自動で戻ります）
    • 
        
  • ポート選択 — サイドパネルの Options セクションにある Joystick 1 / Joystick 2 のプルダウンで、接続中のゲームパッドをどちらのポートに割り当てるか選べます。1P用プログラムは通常 Joystick 1 を使用します
    • 
        
  • ボタン割り当て — 左スティック / D-pad = 方向、A/X ボタン = トリガー1、B/Y ボタン = トリガー2
    • 
        
  • 2P対応 — 2 台目のゲームパッドは、もう一方のプルダウンで選ぶと 2P 側として使えます
    • 
        


        
キーボード

        
キー配置の全体図、FM-7 固有のキー（BREAK / GRPH / カナ / HOME など）が日本語配列・英語配列のどのキーに当たるか、キーの割り当ての変え方は キーボードマニュアル に図入りでまとめています。

        
    
        
  • キー入力方式 — 物理キーの位置でマッピングしています。JIS配列（106/109キー）・US配列（101/104キー）のどちらでも同じ配置で使えます
    • 
        
  • クリックで入力（ソフトウェアキーボード） — Keyboard パネルのキーボード図のキーをクリックすると、その文字がシミュレータに入力されます（テンキーの = と EL / CLS / DUP は入力に対応していません。スキャンコード方式ではテンキーの + も入力できず、HOM は DEL と同じ入力になります）。Shift と CTR はスティッキー（押すたびに ON / OFF が切り替わり、次のキーを押して離すと自動で戻ります。CTR は入力コードの無いキーでは戻りません）、GRPH は押している間のみ、CAP / カナ はトグル動作です。タッチ端末では画面下部のソフトウェアキーボードでも同様に入力できます
    • 
        
  • Cursor → Ten Key — テンキーのないキーボード向けのオプションです。サイドパネルの Options セクションでチェックを入れると、カーソルキー（↑↓←→）がテンキーの 8/2/4/6 として動作します。テンキーを使うプログラムに便利です
    • 
        
  • キーカスタマイズ — Keyboard パネルの「キーカスタマイズ」で、お使いの物理キーボードを配列（日本語配列 / 英語配列）と種別（フルキー / テンキーレス / コンパクト）で選べます。「カスタマイズ開始」を押し、割り当てたい FM-7 キーをクリックしてから物理キーを押すと、そのキーが割り当てられます。割当は保存され、「リセット」で既定に戻せます（手順は キーボードマニュアル の第 5 章）
    • 
        
  • BREAK キー — デフォルトでは Esc キーまたは Pause キーが BREAK キーに割り当てられています（PC の Esc の位置が BREAK です）。FM-7 の ESC キーは、日本語配列の 半角/全角（英語配列の `）の位置です。変更は「キーカスタマイズ」と共通で、「カスタマイズ開始」を押してキーボード図の BRK キーをクリックし、割り当てたい物理キーを押します（Pause は常に予備として有効）。「リセット」で既定に戻ります
    • 
        
  • 英語配列向けの代替入力 — _ キーが無い配列では Ctrl + / で _ を入力できます（@ は P の右の [ キーにそのまま割り当たっています）
    • 
        
  • CAPS / カナ / INS — それぞれ CapsLock / 右Alt（またはカナキー） / Insert キーで切り替え。状態は CAP / カナ / INS の LED で確認できます
    • 
        


        
スマートフォン / タブレット

        
タッチ端末では画面下部にソフトウェアキーボードを表示します。キーをタップしてシミュレータに入力できます。

        
    
        
  • 縦向き専用レイアウト — 縦向きのスマートフォンでは、カーソルキー・編集キー・テンキーをメインキーの下段にまとめた縦長専用レイアウトへ自動で切り替わり、キーを大きく描画します。画面の回転に追従します
    • 
        
  • 画面直下にドック — ソフトウェアキーボードは画面のすぐ下に表示されます。右上の × で閉じ、モバイルアクションバーのキーボードボタンで再表示できます
    • 
        


        
スクリーンショット

        
画面下のツールバーにある 📷 ボタンで、現在の画面をPNG画像として保存できます。640×200モード・320×200モードともに 640×400 ピクセルで保存されます。


        
フルスクリーン

        
画面のすぐ下、表示倍率トグルの右端にある FULL ボタンまたは F11 キーでシミュレータ画面をフルスクリーン表示できます。元に戻すには F11 キーを押します。
